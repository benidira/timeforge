# Castov for VS Code

The official zero-server developer toolkit directly in your editor!

## Features
- **Encode to Base64**: Select text, right-click, and encode to Base64 instantly.
- **Decode Base64**: Select Base64 text, right-click, and decode to plain text.
- **Insert UUID v4**: Instantly generate and insert a random UUID wherever your cursor is.

More tools coming soon!
